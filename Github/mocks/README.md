# Git mock files

The files in this directory are small text fixtures for Git exercises:

- [`mock1`](mock1)
- [`mock2`](mock2)
- [`mock3`](mock3)

Each file contains the same sample line. Edit one file, commit it on a practice branch, and use that commit for a cherry-pick exercise documented in [`../README.md`](../README.md).

The fixtures contain no application logic and no external dependencies.
